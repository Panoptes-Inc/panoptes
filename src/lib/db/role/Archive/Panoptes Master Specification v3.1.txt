1. Product Definition

Panoptesは

「競合・業界・自社の構造を読み、
戦略を可視化し、
実行優先順位まで導く戦略OS」

である。

Panoptesは以下ではない

- トラフィック推定ツール
- アナリティクスツール
- Similarweb系
- SEOツール
- LP改善ツール

Panoptesは以下である

- 構造理解装置
- 因果説明装置
- 戦略提案装置
- 実行優先順位エンジン
- 思考圧縮UI
- 戦略OS

---

2. MVP Absolute Rules

MVPで使用するデータは以下のみ

・サイト内部構造
・サイトビジュアル構造
・競合比較
・Engine計算
・AIによる理解と文章化

MVPで使用しない

・流入推定
・滞在時間
・CVR
・広告データ
・GA統合
・外部市場データ

5. Crawling Architecture

Panoptesは

AIクローリングを行わない。

すべてのクロールは
機械的クローリングで行う。

クローリングエンジン

Python crawler

理由

・再現性
・コスト
・スケール
・差分検知
・Feed/Radar対応

---

6. Crawl Modes

Panoptesは3種類のクロールを持つ

1 bootstrap crawl
2 analysis crawl
3 monitoring crawl

---

bootstrap crawl

目的

サイトの基本推定

取得

・top
・navリンク
・footerリンク
・代表ページ

推定

・業界
・サイトタイプ
・構造タイプ
・競合候補

---

analysis crawl

目的

完全分析

対象

最大30ページ

優先ページ

・top
・pricing
・feature
・faq
・case
・contact

ここで

Internal evidence
Visual evidence

を取得する

---

monitoring crawl

目的

競合監視

・差分検知
・Feed生成
・Radar生成

対象

主要ページのみ

最大10ページ

7. URL Discovery Rules

取得対象

・同一ドメイン
・HTMLページ
・nav / footer / CTAから辿れるページ

除外

・ログイン
・cart
・checkout
・session URL
・PDF
・画像
・zip
・外部リンク
・検索ページ

URLは正規化する

・tracking削除
・fragment削除
・canonical優先

11. Diff Detection

Panoptesは差分検知を行う

Level2

Level3
構造差分

・CTA変更
・pricing追加
・faq追加

Level4
意味差分

ここだけAI
