Panoptes Python Crawler Implementation Specification v1.0

Purpose
Panoptesのサイト観測レイヤーを構築するためのPythonクローラー実装仕様。
本クローラーはAIクローリングを行わず、機械的観測と構造抽出を担当する。

役割
・URL取得
・HTML取得
・内部リンク探索
・構造抽出
・スクリーンショット取得
・差分検知
・Observation bundle生成素材作成

AIの役割
・構造意味理解
・Visual理解
・戦略文章化

CrawlerはAI処理を行わない。
