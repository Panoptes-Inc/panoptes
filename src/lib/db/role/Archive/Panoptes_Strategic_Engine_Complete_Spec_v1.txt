Panoptes Strategic Engine Complete Specification v1.0
作成日: 2026-03-11

Purpose
Panoptesの中核であるStrategic Engineの完全仕様。
本仕様は、Internal / Visual 観測結果を統合し、
業界構造、自社差分、優先度、戦略カード、30/60/90日プランの骨格までを
一貫して生成するためのロジックを定義する。

本仕様の役割
・観測結果を戦略スコアへ変換する
・競合比較と業界構造推定を行う
・自社の改善余地を算出する
・優先施策を生成する
・戦略OSとして一貫した再現性を持たせる

重要原則
・LLMに計算させない
・LLMは意味理解と文章化のみ
・計算はEngine側で実行
・全タブは同一snapshotを参照
・計算式は再分析で再現可能であること

3. 戦略評価軸（固定）
--------------------------------------------------

Panoptesの戦略評価は6軸固定。

A1 価値訴求
A2 情報階層
A3 導線強度
A4 信頼構造
A5 差別化明確性
A6 意思決定支援

Internal / Visual 両方を同じ6軸にマップする。

--------------------------------------------------
5. Layer別スコア
--------------------------------------------------

各軸について Internal と Visual を別々に計算する。

I_i = Internal axis score
V_i = Visual axis score

計算方法
axisScore = 100 * weighted_mean(valid_submetrics)

weighted_mean は null を除外して計算する。

例
I_1 = 100 * weighted_mean(
  hero_value_clarity,
  problem_solution_alignment,
  benefit_specificity,
  offer_visibility
)

同様に V_1 も Visual観測値から計算。

--------------------------------------------------
6. Layer総合スコア
--------------------------------------------------

Internal総合
I = Σ(a_axis[i] * I_i)

Visual総合
V = Σ(a_axis[i] * V_i)

初期軸重み（合計1.0）
A1 価値訴求         0.19
A2 情報階層         0.16
A3 導線強度         0.18
A4 信頼構造         0.16
A5 差別化明確性     0.15
A6 意思決定支援     0.16

--------------------------------------------------
7. 総合スコア T
--------------------------------------------------

Panoptesは Internal と Visual を単純平均しない。
調和平均を用いる。

T = 1 / ((0.6 / I) + (0.4 / V))

理由
・片方だけ高いサイトを過大評価しない
・構造と見た目の両方が必要だから

--------------------------------------------------
8. Confidence調整
--------------------------------------------------

各レイヤーには confidence を持たせる。

c_internal
c_visual
c_benchmark

範囲
0.0 - 1.0

T_adj =
T * (0.90 + 0.10 * min(c_internal, c_visual))

目的
・観測不足時の過信を防ぐ
・視覚取得失敗時のスコア暴れを抑える

--------------------------------------------------
9. Coherence補正
--------------------------------------------------

Panoptesは整合性を見る。

Coherence項目
C1 NAV coherence
C2 DECISION coherence
C3 MESSAGE coherence

各0.0 - 1.0

Coherence_avg = mean(C1, C2, C3)

最終スコア
T_final = T_adj + 5 * (Coherence_avg - 0.5)

補正幅
-2.5 〜 +2.5

目的
・構造は強いのに伝達がブレるケースを補正
・見た目は良いが意思決定が繋がらないケースを補正

--------------------------------------------------
10. Self / Competitor / Industry 比較
--------------------------------------------------

各対象に対して以下を計算する

I_i
V_i
S_i = 0.6 * I_i + 0.4 * V_i

Selfと競合群から業界ベンチマークを作る。

Industry_Max_i = max competitor S_i
Industry_Avg_i = mean competitor S_i
Avg_best_i = 業界上位群平均（デフォルト上位30%）

--------------------------------------------------
11. 業界差分
--------------------------------------------------

自社差分

Delta_Industry_i = Self_S_i - Avg_best_i
Gap_to_Leader_i = Self_S_i - Industry_Max_i

これにより
・業界上位平均との差
・業界トップとの差
を同時に見る。

--------------------------------------------------
12. Opportunity計算
--------------------------------------------------

Opportunity_i は
「市場における戦略余地」を示す。

基本発想
・業界全体で弱い軸ほど余地がある
・分散が大きい軸は競争余地がある
・上位群がすでに飽和している軸は余地が低い

初期式
Opportunity_i =
0.45 * normalize(100 - Industry_Avg_i)
+ 0.35 * normalize(axis_variance_i)
+ 0.20 * normalize(100 - Avg_best_i)

出力
0 - 100

--------------------------------------------------
13. Priority計算
--------------------------------------------------

Priority_i は
「今どの軸を改善すべきか」を示す。

初期式

Priority_i =
0.50 * normalize(-Delta_Industry_i)
+ 0.30 * normalize(Opportunity_i)
+ 0.20 * a_axis[i]

解釈
・業界上位との差が大きいほど優先
・市場余地が高いほど優先
・もともと重要度の高い軸を少し優遇

出力
0 - 100

19. Strength / Issue 抽出
--------------------------------------------------

自社分析で表示する

は以下のルールで決める。

強み

課題

・または重大flagあり

各カード構成
・戦略意図
・根拠

--------------------------------------------------
23. Confidence Rules
--------------------------------------------------

confidenceは最低以下から計算する。

c_internal
・取得ページ数
・必須ページ種別のカバー率
・missing field率

c_visual
・スクリーンショット取得成功率
・対象ページ数
・cropped evidenceの有無

c_benchmark
・競合数
・競合ページ取得成功率
・分布の安定性

confidenceは narrative にも反映する。
confidenceが低い場合は断定を弱める。

27. Engine Versioning
--------------------------------------------------

Engine出力には version を持たせる。

例
engine_version = "strategic_engine_v1_0"

理由
・再分析時の互換性
・計算ロジック変更時の比較
・将来の研究用

--------------------------------------------------
28. 最終原則
--------------------------------------------------

Panoptes Strategic Engineは

観測事実
↓
数学的変換
↓
戦略意味
↓
意思決定支援

を一貫して行う。

AIは意味を与えるが、
Engineが一貫性を保証する。

Panoptesは
「AIが答えを出すツール」ではなく
「戦略の地図と優先順位を生成するOS」
である。
